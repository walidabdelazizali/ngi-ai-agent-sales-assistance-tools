# TASK

## Goal
- Define one narrow sprint objective with deterministic, testable completion criteria.

## Constraints
- No architecture changes.
- No routing/API changes.
- No business logic redesign.
- No new dependencies.
- No autonomous behavior additions.

## Required
- Explicit in-scope files.
- Explicit out-of-scope items.
- Clear acceptance checks.
- Bounded implementation notes.

## Validation
- Run only required tests/checks for the scope.
- Confirm no unintended file changes.
- Confirm deterministic behavior is preserved.
