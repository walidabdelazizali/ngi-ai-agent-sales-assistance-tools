# Director One-Pager

## The Business Problem
Insurance sales and support teams struggle to answer complex plan and network questions quickly and accurately. Manual lookups are slow, error-prone, and create friction for both staff and customers.

## What the Current System Does
This system provides a controlled, CLI-based toolset for:
- Instantly answering plan benefit and network coverage questions
- Comparing plans on key benefits
- Supporting both English and Arabic queries
- Producing structured, business-ready outputs from curated data

## Where It Creates Value
- Reduces time to answer for sales/support
- Improves accuracy and consistency of responses
- Enables rapid onboarding of new staff
- Demonstrates readiness for digital transformation in insurance operations

## Why This Phase Is Narrow and Controlled
- Focuses only on stable, validated features
- Avoids speculative AI or untested automation
- Ensures every demo is reliable and reproducible
- Builds trust with leadership before expanding scope

## What Approval from Leadership Would Unlock Next
- Broader plan and network coverage
- User-friendly interfaces (web, chat, etc.)
- Integration with live data sources
- Optional AI-powered enhancements after core stability
