# Known Scope and Limitations

## In Scope Now
- CLI-based plan and network queries (English/Arabic)
- Plan field, summary, and comparison for curated plans
- Provider lookup and network tier/status
- Structured outputs from sample data

## Not in Scope Now
- DOCX ingestion (no input files in demo)
- Web, chat, or bot interfaces
- Live data integration or real-time updates
- AI/RAG/LLM features
- Automated error handling for all edge cases

## What Should Not Be Claimed in the Demo
- Any AI or chatbot capability
- Real-time or live data access
- Full market coverage (only demo plans/providers)
- Automated document ingestion
- User-facing GUI or self-service portal
