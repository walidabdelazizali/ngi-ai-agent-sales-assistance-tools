# Architecture

> **Current phase: Scaffold only — no business logic implemented yet.**

## Folder Structure

| Folder | Purpose |
|---|---|
| `src/extractors/` | Future extraction logic for input documents |
| `src/normalizers/` | Future data cleaning and normalization |
| `src/validators/` | Future validation rules for extracted data |
| `src/db/` | Future database access layer |
| `src/tools/` | Future shared utility functions |
| `src/agent/` | Future AI agent orchestration |
| `src/config/` | Future configuration and settings |
| `input_docs/` | Drop zone for source documents to process |
| `output/` | Generated results and reports |
| `runtime_data/csv/` | Intermediate CSV files produced at runtime |
| `runtime_data/workbook/` | Intermediate Excel workbooks produced at runtime |
| `scripts/` | Bootstrap and runner scripts (PowerShell) |
| `tests/` | Automated tests |
| `docs/` | Project documentation |
| `data/` | Static reference data |
